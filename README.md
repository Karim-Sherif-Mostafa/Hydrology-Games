# Hydrology-Games# 💧 HydroQuest — Engineering Hydrology Learning Game

An interactive, browser-based educational game for engineering hydrology students.
**10 progressive levels** covering the full hydrology curriculum — with live
hydrograph simulation, auto-graded calculations, and randomized problem values
so every student gets a unique challenge.

No installation required — runs in any modern browser (desktop, tablet, or mobile).

## 📚 Learning Content

| Level | Topic | Key Concepts |
|-------|-------|--------------|
| 1 | 🌊 Water Cycle | Stores, fluxes, pan evaporation |
| 2 | 🌧️ Rainfall | Tipping-bucket gauges, depth → volume conversion |
| 3 | 🗺️ Areal Rainfall | Thiessen polygons, weighted averages |
| 4 | 🏞️ Runoff | Rational Method (Q = CiA/3.6), runoff coefficient |
| 5 | ⏱️ Time of Concentration | Kirpich equation + live simulator |
| 6 | 🌱 SCS Curve Number | Retention S, runoff Q = (P−0.2S)²/(P+0.8S) |
| 7 | 📈 Hydrograph Challenge | Unit hydrograph, peak discharge (SCS-CN + triangular UH simulator) |
| 8 | 🚧 Dams & Reservoirs | Reservoir mass balance, flood storage |
| 9 | ⚖️ Catchment Water Balance | P = R + ET + ΔS, runoff coefficient |
| 10 | 🏆 Master Hydrologist | Return period, probability, final challenge |

## ✨ Features

- 🔬 **Live hydrograph simulator** — adjust catchment length, slope, area,
  rainfall depth/duration, and curve number; watch the hyetograph and
  runoff hydrograph update in real time
- 🔢 **Auto-graded calculations** — instant feedback with full worked solutions
- 🎲 **Randomized values** — every play session generates different numbers,
  preventing answer-sharing
- 🔒 **Progressive unlocking** — complete a level to unlock the next
- ⭐ **Scoring & stars** — points per correct answer, 1–3 stars per level
- 💾 **Progress saved locally** — students can leave and resume on the same device
- 📱 **Responsive design** — works on phones, tablets, and computers
